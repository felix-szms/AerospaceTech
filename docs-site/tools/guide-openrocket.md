# 📖 OpenRocket 切换中文界面指南

> OpenRocket 内置简体中文翻译，切换后即可全中文使用！本指南 1 分钟完成设置。

## 一、下载安装

1. 访问官网：https://openrocket.info/
2. 点击 **Download**（下载）
3. 下载 **"Installer"安装包**（Windows）或 **".jar 免安装版"**（机房推荐，放共享目录）
4. 安装版双击安装；jar 版需电脑装有 Java（机房一般已有）

## 二、切换中文界面（关键步骤）

1. 启动 OpenRocket，默认是英文界面
2. 菜单栏点 **Edit（编辑）→ Preferences（首选项）**
3. 在弹窗中找到 **Options（选项）** 标签页
4. 找到 **Language / 语言** 下拉框
5. 选择 **中文（中国）zh_CN**
6. 点 **OK** → **重启 OpenRocket**
7. ✅ 界面变成全中文！

```
Edit → Preferences → Options → Language: 中文（中国） → OK → 重启
```

## 三、中文界面常用菜单对照

| 英文菜单 | 中文菜单 | 用途 |
|---|---|---|
| File → New | 文件 → 新建 | 新建火箭设计 |
| Analyze → Rocket optimization | 分析 → 火箭优化 | 优化设计参数 |
| Simulation → New simulation | 仿真 → 新建仿真 | 跑飞行仿真 |
| Side view / Back view | 侧视图 / 后视图 | 查看火箭外形 |
| Stability | 稳定性 | 看重心/压心标记 |

## 四、第 12 课任务速览（中文界面下）

1. **新建火箭**：文件 → 新建
2. **添加部件**：右侧部件树，依次添加 机身管/鼻锥/尾翼/发动机
3. **选发动机**：点击 Motor Mount → 选 A8-3
4. **跑仿真**：仿真 → 新建仿真 → 运行，看最高点是否达到 100m
5. **看稳定性**：设计窗口中蓝色圆点（重心）需在红色圆点（压心）**上方至少 1 倍口径**

## 五、常见问题

| 问题 | 解决 |
|---|---|
| 找不到语言选项 | 版本过旧，去官网下最新版（22.02+）|
| 切换后部分还是英文 | 个别词条未翻译，不影响使用 |
| 打不开 jar | 先装 Java 运行时（java.com 免费下载）|
