# 📖 NASA FoilSim 中文使用指南

> FoilSim III 是 NASA 官方翼型实验室。首次加载约 30-60 秒（CheerpJ 技术），加载完成后操作非常流畅。
> 本指南帮你 3 步上手，附术语对照表和探究任务。

## 一、打开与等待

1. 点击工具链接 → 浏览器出现 NASA 页面
2. 中间黑色区域会显示 **"Loading simulation..."（正在加载模拟器）**——这是正常的，等待 30-60 秒
3. 出现翼型图和滑块即加载完成

> 💡 提示：如果等了 2 分钟还没加载出来，刷新重试一次；仍不行则改用[本站升力演示器](/tools/aerodynamics-lab)（功能覆盖课堂需求）。

## 二、界面分区说明

```
┌─────────────────────────────────────────┐
│  顶部：选择飞行条件（Flight Test）        │
│  ┌──────────────┬──────────────────────┐ │
│  │              │  右侧：参数滑块区      │ │
│  │  中间：翼型   │  • Angle 迎角        │ │
│  │  + 气流可视化 │  • Camber 弯度       │ │
│  │  （拖动看变化）│  • Thickness 厚度    │ │
│  │              │  • Speed 风速        │ │
│  │              │  • Altitude 高度     │ │
│  └──────────────┴──────────────────────┘ │
│  左下：输出数值（Lift 升力 / Drag 阻力）   │
└─────────────────────────────────────────┘
```

## 三、必会术语对照表

| 英文 | 中文 | 说明 |
|---|---|---|
| **Angle (of Attack)** | 迎角 | 翼弦与来流的夹角，最核心变量 |
| **Camber** | 弯度 | 翼型弯曲程度，越大升力越大 |
| **Thickness** | 厚度 | 翼型厚薄 |
| **Lift** | 升力 | 输出值，单位磅(lb)或牛顿 |
| **Drag** | 阻力 | 输出值 |
| **Stall** | 失速 | 迎角过大升力骤降 |
| **Shape/Airfoil** | 翼型 | 可选不同 NACA 编号翼型 |
| **Plot** | 绘图 | 查看升力-迎角曲线 |

## 四、探究任务（配合第 3 课）

**任务 A：迎角-升力关系**
1. 固定 Speed=100、Camber=0
2. Angle 从 0° 开始，每次 +2°，记录 Lift 值（共 10 组）
3. 画出"迎角-升力"图：线性段斜率是多少？几点失速？

**任务 B：风速的平方关系**
1. 固定 Angle=5°
2. Speed 从 50 → 100（翻倍），Lift 变了几倍？（应为 4 倍）

**任务 C：翼型对比**
1. 在 Shape 菜单选两个不同翼型（如对称 vs 高弯度）
2. 同参数下谁的升力大？谁先失速？

## 五、常见问题

| 问题 | 解决 |
|---|---|
| 一直 Loading | 刷新；换 Chrome/Edge；网络差时用本站工具替代 |
| 数值单位是 lb | 教师可让学生换算：1 lb ≈ 4.45 N |
| 界面看不懂 | 对照上面第二节的分区图 |
